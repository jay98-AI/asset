Search protocol (proposed)

Format: comma-separated terms, any order. Example: Arjun, ep01, sc03
Recognized patterns: ep01, ep1, episode 1 → episode · sc03, s3, scene 3 → scene · s2 style season only with S2E01 · anything else → matched against character, location, props, project name.
Logic: terms combine with AND (narrows results). Ranges: sc03-05. Exclude: -props not included in v1.
Feedback: each term turns into a chip showing how it was read; click a chip to change its field (e.g. Arjun as character vs. location) or remove it. Unrecognized terms show as "text match".
Autocomplete: typing suggests known characters, locations and props; typing "ep" or "sc" suggests existing numbers for the chosen project.
Open: if "Arjun" is both a character and a location name, show both groups ("Characters 12 · Locations 2")?
